# 自制练习材料：先自己建目录，再用这里核对

正文要求亲手建立目录、输入规则、复制和改名。这里的文件用于核对或重新取回模拟材料，不代替学习步骤，也没有已完成的运行结果。

```text
你自己建立的 AI学习/
├── 保留原文/
│   └── 读书角规则.txt
├── day03/                      ← WorkBuddy只选这个目录
│   └── 读书角规则-副本.txt      ← 开始时只有这一份
└── 第3天记录.txt                ← 完成后由你自己保存
```

本附件中的 `AI学习/day03` 也仅有一份副本；原文在它的同级目录 `保留原文` 内。记录模板放在附件外层，不混进指定练习目录。没有示例输出，也没有已经生成的说明文档。

仓库里的文章目录 `day03` 和你自己建立的 `AI学习/day03` 只是同名，不是同一个位置。不要把 GitHub 的文章章目录 `day03`、整个 `practice`、整个下载仓库或 `AI学习` 父目录直接选给任务。先按照正文亲手建自己的练习目录，确认实际位置，不把同名目录当成同一路径。

不使用真实规定、通讯录或隐私信息。不自动运行命令，不连接外部账号。记录是空白模板，须亲自核对填写；不要用示例代替真实结果。
