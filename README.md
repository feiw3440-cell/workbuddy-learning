# WorkBuddy 零基础学习手册

> [!IMPORTANT]
> 本仓库是全系列唯一的课程首页。Day 01 已于 2026-11-18（北京时间）发布。Day 02 已于 2026-11-19（北京时间）发布。Day 03 已于 2026-11-20（北京时间）发布。第 4–21 单元只有学习路线，没有课文，也不提供课文链接。本课程未安装或登录实测。

从解释 AI 是什么开始，按能检查的小成果往下练。21 个单元是建议顺序，不是 21 天保证精通，也不是每天自动运行。同一天可以做完多个单元；每天只有约 30 分钟时，一个单元可以拆开做。

全部课文都放在这个仓库，不按天另建仓库。
