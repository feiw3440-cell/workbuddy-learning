# 自制练习材料：先自己建目录，再用这里核对

正文要求把已经核对过的规则、汇总、图和结论复制进你自己的 `day06`。这里的文件用于核对或重新取回教学材料，不代替学习步骤，也没有学生已经做好的大纲、PPT 或最终版讲稿。

```text
你自己建立的 AI学习/
├── 保留原文/
│   ├── 读书角规则.txt
│   ├── 借阅分类汇总-最终版.csv
│   ├── 借阅分类柱状图-教学示例.png
│   ├── 借阅三句结论-教学示例.txt
│   ├── 四页汇报大纲-教学示例.md          ← 教学示例，留在外面
│   └── 读书角四页讲稿-降级版-教学示例.md  ← 教学示例，留在外面
├── day06/                                  ← WorkBuddy只选这个目录
│   ├── 读书角规则-副本.txt
│   ├── 借阅分类汇总-最终版-副本.csv
│   ├── 借阅分类柱状图-教学示例-副本.png
│   └── 借阅三句结论-教学示例-副本.txt      ← 开始时只有这些输入副本
└── 第6天记录.txt                            ← 完成后由你自己保存
```

本附件中的 `AI学习/day06` 也只有这四份副本。原文、四页大纲教学示例和讲稿降级教学示例在同级目录 `保留原文`。记录模板放在附件外层。

汇总 CSV 含表头共 7 行。12 是合计条数，对应含重复的 12 次借阅，不是 12 行明细。主口径是绘本 4、小说 4、科普 2、工具书 1、空分类 1，合计 12。绘本和小说并列最多。空分类不是图书类别。这些图、结论、大纲和讲稿都标明是教学示例，不是客户端实测产物。

仓库里的文章目录 `day06` 和你自己建立的 `AI学习/day06` 只是同名，不是同一个位置。不要把 GitHub 的文章章目录 `day06`、整个 `practice`、整个下载仓库或 `AI学习` 父目录直接选给任务。不要覆盖输入副本，也不要改 `day03` 和 `day05`。

不使用真实汇报或隐私信息。不自动运行命令，不连接外部账号。记录是空白模板，须亲自核对填写。
