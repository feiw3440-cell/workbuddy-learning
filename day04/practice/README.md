# 自制练习材料：先自己建目录，再用这里核对

正文要求亲手建立目录、保存 12 行表、复制和改名。这里的文件用于核对或重新取回模拟材料，不代替学习步骤，也没有已完成的汇总。

```text
你自己建立的 AI学习/
├── 保留原文/
│   └── 读书角借阅记录.csv
├── day04/                          ← WorkBuddy只选这个目录
│   └── 读书角借阅记录-副本.csv      ← 开始时只有这一份
└── 第4天记录.txt                    ← 完成后由你自己保存
```

本附件中的 `AI学习/day04` 也仅有一份副本；原表在它的同级目录 `保留原文` 内。记录模板放在附件外层，不混进指定练习目录。没有汇总结果，也没有图表。

仓库里的文章目录 `day04` 和你自己建立的 `AI学习/day04` 只是同名，不是同一个位置。不要把 GitHub 的文章章目录 `day04`、整个 `practice`、整个下载仓库或 `AI学习` 父目录直接选给任务。先按照正文亲手建自己的练习目录，确认实际位置，不把同名目录当成同一路径。

表里故意留着一处空分类和一处完全重复。不要先把表“整理干净”再交给练习。不使用真实借阅记录或隐私信息。不自动运行命令，不连接外部账号。记录是空白模板，须亲自核对填写；不要用示例次数代替自己的抽算。
