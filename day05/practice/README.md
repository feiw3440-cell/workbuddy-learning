# 自制练习材料：先自己建目录，再用这里核对

正文要求把第4天已经核对过的汇总复制进你自己的 `day05`。这里的文件用于核对或重新取回教学汇总，不代替学习步骤，也没有已经画好的图或写好的三句结论。

```text
你自己建立的 AI学习/
├── 保留原文/
│   ├── 借阅分类汇总-最终版.csv
│   └── 借阅分类汇总说明.md
├── day05/                                  ← WorkBuddy只选这个目录
│   └── 借阅分类汇总-最终版-副本.csv         ← 开始时只有这一份
├── 借阅分类柱状图-最终版…                  ← 做完后由你自己另存，不要提前放入
├── 借阅三句结论-最终版…                    ← 做完后由你自己另存，不要提前放入
└── 第5天记录.txt                            ← 完成后由你自己保存
```

本附件中的 `AI学习/day05` 也仅有一份汇总副本。原表和口径说明在同级目录 `保留原文` 内。记录模板放在附件外层。没有柱状图，也没有结论文件。

这份 CSV 是 7 行汇总：表头，加上绘本、科普、小说、工具书、空分类和合计。它对应第4天 12 条含重复记录的统计结果，不是那张 12 行借阅明细。主口径是绘本 4、小说 4、科普 2、工具书 1、空分类 1，合计 12。绘本和小说并列最多。空分类不是图书类别。去重只把小说改为 3，作为对照，不能和含重复合在同一张图里。

仓库里的文章目录 `day05` 和你自己建立的 `AI学习/day05` 只是同名，不是同一个位置。不要把 GitHub 的文章章目录 `day05`、整个 `practice`、整个下载仓库或 `AI学习` 父目录直接选给任务。

不使用真实借阅记录或隐私信息。不自动运行命令，不连接外部账号。记录是空白模板，须亲自核对填写；不要用示例图代替自己生成的图。
